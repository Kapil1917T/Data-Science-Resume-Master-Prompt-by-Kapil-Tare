# 🧠 Data Science Resume Master Prompt by Kapil Tare

Welcome to the public release of my **Master Prompt** — a structured, recruiter-realistic framework designed to help data professionals tailor their resumes, cold emails, and LinkedIn messages with precision and truth.

This framework has been iterated **500+ times** across GPT-5, Claude 4.5, and Gemini Advanced to create an end-to-end system that aligns resumes with recruiter psychology and ATS parsing logic.

## 🧩 How To Use

1. **Read the disclaimers in the PDF first** — they explain how to avoid common mistakes like LLM hallucinations and ATS formatting issues.  
2. **Provide the templates** (ATS and 1-pagers) to your chosen LLM (GPT-5, Claude, Gemini) before running the prompt.  
3. **Run the Master Prompt** from the PDF directly in your model of choice.  
4. **Manually verify** every tweak — do *not* accept generated metrics, clients, or tool names without checking against your real experience.  
5. **Export** clean versions (DOCX/PDF) once you’re satisfied with the tailored output.

---

## 🚨 Disclaimers

- Keep your **ATS resume plain and simple** — avoid fancy symbols, graphics, and text boxes.  
- **LLMs can still hallucinate** — cross-check all content manually.  
- Your **Group A / Group B 1-pager themes** will be unique. The ones in my example were:  
  - *Group A → Marketing Analytics, Pricing & Forecasting*  
  - *Group B → Product Analytics, Experimentation & GTM Strategy*

## 🧭 Purpose

The Master Prompt’s goal is not automation — it’s **consistency, realism, and clarity**.  
It enforces:
- factual verification of every bullet  
- clean synchronization across ATS and recruiter versions  
- recruiter-psychology-based outreach templates  

Use it as a **baseline system**, not a black box.

## 💡 Commands Supported (inside the prompt)

| Command | Description |
|----------|--------------|
| **TAILOR** | Parse a job description and create all three resume versions |
